# Archive: the retired agent harness

Everything in this folder belonged to the agent harness that ran from 2026-10-05 to 2026-10-06: the master source of
truth, the operations manual, the state file and ledger, the slice contract, the handoffs, the prompts and templates,
the evidence and review reports, the design intake procedure and registry, and the harness scripts
(`scripts/agent/`).

The owner retired it on 2026-10-06 (`../decisions/ADR-0018-retire-the-harness.md`). It's kept for history. Don't
follow it, and don't run its scripts: start with `PLAN.md` and `AGENTS.md` at the repo root.
